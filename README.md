# יסודות החשמל — קורסים ותרגול

```bash
python3 -m pip install -r requirements.txt
streamlit run Electricity-circuit.py
```

לאחר אישור תנאי השימוש הראשון מוצגת בחירת קורס:

- **מיזוג וקירור:** התרגול הקיים; ברמות א׳ וב׳ של חוק אוהם, 9 מתוך 20 תרגילים דורשים מציאת התנגדות ממתח והספק. מבחן עיוני מוגן בסיסמה מגריל 20 שאלות מהמאגר המאוחד של 193 שאלות, מערבב אפשרויות ומציג בסיום דף ציון עם שם הלומד, וממנו כפתור נפרד לסקירת התשובות.
- **מיגון:** התרגול הקיים, שני סוגי מעגלים מעורבים לפי דף הדוגמאות, וסוללות עם 70% שאלות מטען ו־30% שאלות אנרגיה. בכל סבב 10 תרגילי מעגל מעורב: חמישה עם קבוצות מקבילות ונגדים בטור, וחמישה עם ענפי טור המחוברים במקביל. לכל נגד מחושבים הזרם, המתח וההספק, לצד ההתנגדות הכוללת והזרם מהמקור. הפתרון מציג נוסחה וסכמה אחרי כל שלב צמצום.
- **סלולר:** רמות א׳ וב׳ בלבד ושני ענפים בכל תרגיל מקבילי. סוללות עם מטען באמפר־שעה, טעינה, פריקה והתנגדות פנימית. בשאלות ההתנגדות הפנימית מוצגת סכמה של סוללה עם נגד פנימי בטור לעומס המייצג את מעגלי הטלפון; ערכים שטרם חושבו מסומנים בסימן שאלה.

התקדמות התרגול נשמרת בנפרד לכל קורס בדפדפן. מבחנים שהושלמו מוצגים בגרף של אחוז תשובות נכונות לפי מספר מבחן. המבחן הנוכחי והבחירות נשמרים בדפדפן, וכניסה לאחר רענון דורשת סיסמה תקפה. שאלות שלא נענו נחשבות שגויות לאחר אישור הגשה.

ההגרלה מעדיפה שאלות שטרם נצפו ומסיימת סבב של המאגר לפני חזרה לשאלות ישנות. עם המאגר הנוכחי כל מבחן מכיל 20 שאלות שאינן במבחן הקודם. אם המאגר יצומצם, מותרות עד חמש חזרות מהמבחן הקודם; ההגרלה מסרבת לפעול אם אין די שאלות לעמוד בכלל.

## ניהול דרך QA — שימוש שוטף

יש שלושה פרטים שונים, וכל אחד מיועד למשהו אחר:

| פרט | למה הוא משמש | איפה מגדירים אותו |
| --- | --- | --- |
| סיסמת QA | כניסת המנהל למסך הניהול | ב־Streamlit Secrets; ברירת המחדל הקיימת נשמרה |
| סיסמאות התלמידים | כניסה לשאלות העיוניות במיזוג וקירור | בתוך האתר, במסך QA |
| טוקן GitHub | חיבור טכני לשמירה קבועה של ההגדרות | פעם אחת ב־Streamlit Secrets |

1. בתחתית האתר לחצו **QA**, הזינו את סיסמת המנהל והיכנסו.
2. לשאלות העיוניות לחצו **שאלות עיוניות במיזוג — כניסת מנהל**. הכפתור זמין גם כשאתם בקורס מיגון או סלולר. אין צורך בסיסמת תלמיד, וגם רשימת סיסמאות ריקה אינה חוסמת את המנהל.
3. לניהול לחצו **ניהול סיסמאות**. תראו טבלה עם שם הסיסמה, הסיסמה עצמה, התוקף והמצב שלה. הרשימה מוצגת למנהל בלבד.
4. להוספה לחצו **הוספת סיסמה**, מלאו שם לזיהוי, סיסמה ותאריך, ואז **שמירת הסיסמה החדשה**.
5. לשינוי סיסמה קיימת לחצו **עריכה** בשורה שלה. אפשר להחליף את הסיסמה, לשנות את תאריך התוקף, לשנות שם, לבטל או להפעיל מחדש. בסיום לחצו **שמירת שינויים בסיסמה זו**. שדה החלפה ריק שומר על הסיסמה הקיימת. השמירה אינה משנה סיסמאות אחרות.
6. להסרה לחצו על **האיקס האדום שמשמאל**. ייפתח חלון עם השאלה ״האם אתה בטוח שאתה רוצה להסיר את הסיסמה״ ושם הסיסמה. **כן** מוחק, **לא** משאיר אותה.
7. הסיסמה תקפה עד סוף היום שנבחר, לפי שעון ישראל. מהיום שאחריו היא נחסמת אוטומטית, לרבות ניסיון להמשיך מבחן שכבר התחיל. תאריך ריק משאיר אותה ללא תאריך תפוגה. סיסמה שפג תוקפה נשארת ברשימה כדי שתוכלו להאריך או למחוק אותה.
8. **רענון הרשימה מהשמירה** טוען מחדש את הרשימה השמורה. עריכות שלא נשמרו מתבטלות. שמירת שמות הקורסים נעשית בכפתור נפרד ואינה משנה סיסמאות.

מבחן QA אינו משנה את הציונים או את סבב השאלות האישי. ביציאה מ־QA חוזרים למצב הרגיל, וגישה רגילה למבחן שוב דורשת סיסמת תלמיד תקפה.

סיסמת מנהל נכונה מאפשרת כניסה ל־QA גם כשחיבור השמירה הפרטית אינו תקין. במקרה כזה מוצגת הודעת תיקון מפורשת, ואפשר לבדוק את תרגילי החישוב ולעבור בין הקורסים. רשימת הסיסמאות אינה מוצגת כריקה ואין מעבר לשמירה חלופית. ניהול סיסמאות ומבחנים עיוניים דורשים חיבור תקין; לאחר תיקון החיבור אפשר ללחוץ **בדיקה מחדש של החיבור לשמירה** כדי לטעון את הנתונים המקוריים ללא כניסה נוספת.

### סיסמאות שהוגדרו בגרסה הישנה

הגרסה הקודמת שמרה רק גיבוב לבדיקת הסיסמה, ולכן אין דרך לשחזר את הטקסט שלה. הסיסמאות הישנות ממשיכות לעבוד כל עוד נשמרו בשרת והן בתוקף. כדי להציג סיסמה כזו בטבלה, לחצו **עריכה**, הקלידו אותה פעם אחת בשדה החלפת הסיסמה ושמרו. אפשר גם להגדיר סיסמה חדשה במקום הישנה.

לבקשת המנהל, קודי הכניסה המשותפים לתלמידים נשמרים מעתה גם כטקסט בתצורת הניהול הפרטית כדי לאפשר את הצגתם ב־QA. בדיקת כניסה עדיין משתמשת ב־PBKDF2 עם מלח. הטקסט ורשימת הסיסמאות נשלחים רק אחרי כניסת מנהל מאומתת; התצורה הציבורית מכילה שמות קורסים בלבד. אין להעלות את קובץ הניהול למאגר הציבורי.

### הגדרה חד־פעמית לשמירת סיסמאות

בלי ההגדרה הזאת הסיסמאות נשמרות בשרת הנוכחי, והן עלולות להיעלם אחרי בנייה מחדש של האתר. **אין צורך להקליד סיסמאות תלמידים ב־Secrets**: לאחר החיבור החד־פעמי מנהלים את כולן מתוך QA.

**א. מכינים מקום פרטי לשמירה ב־GitHub**

- היכנסו ל־GitHub וצרו מאגר בשם `electricity-access`, עם האפשרות **Private**. אפשר להשתמש במקום זאת במאגר הפרטי הקיים של ההערות.
- אם נוצר תחת החשבון OBE-26, שמו המלא יהיה `OBE-26/electricity-access`. אם בחרתם שם אחר, השתמשו בשם שבחרתם.
- אין צורך להעלות אליו קובץ ניהול ידנית; האתר ייצור את `course-admin.json` בחיבור הראשון. אם קיימים עדיין נתונים מקומיים בשרת והמאגר החדש ריק, הם מועברים לשמירה הפרטית.

**ב. יוצרים טוקן גישה**

- ב־GitHub לחצו על תמונת הפרופיל → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
- בחרו את החשבון שמחזיק במאגר. תחת **Repository access** בחרו **Only select repositories** ואת המאגר הפרטי של השמירה.
- בהרשאות המאגר הגדירו **Contents: Read and write**, וצרו את הטוקן. תוקף הטוקן הוא תוקף החיבור הטכני ל־GitHub; הוא נפרד מתוקף סיסמאות התלמידים.
- העתיקו את הטוקן ל־Streamlit בשלב הבא. אין להדביק אותו בקוד, במאגר הציבורי או בצ׳אט.

**ג. מחברים ב־Streamlit**

1. פתחו [share.streamlit.io](https://share.streamlit.io) והיכנסו לחשבון שמנהל את האתר.
2. ליד האתר לחצו על שלוש הנקודות → **Settings** → **Secrets**.
3. השאירו את הגדרות המשוב הקיימות. הוסיפו את הסעיף הבא, או ערכו את סעיף `course_admin` אם הוא כבר קיים — אין להוסיף את אותו סעיף פעמיים:

```toml
[course_admin]
password = "210592"
storage_repository = "OBE-26/electricity-access"
storage_token = "PASTE_YOUR_GITHUB_TOKEN_HERE"
```

4. בשורה `password` השאירו את סיסמת ה־QA שבה אתם משתמשים. בשורת `storage_repository` כתבו את השם המלא של המאגר הפרטי. בשורת `storage_token` החליפו רק את הטקסט שבתוך המרכאות בטוקן שהעתקתם מ־GitHub.
5. לחצו **Save**. היכנסו מחדש ל־QA ובדקו שמופיע **שמירה קבועה מחוברת**.
6. צרו סיסמת ניסיון, שמרו ולחצו **רענון הרשימה מהשמירה**. הרשומה אמורה להישאר עם אותו שם, סיסמה ותוקף.

אם הרשימה ריקה למרות שכבר הוגדרו סיסמאות, ייתכן שהנתונים המקומיים אבדו בהפעלה מחדש קודמת. אין דרך לשחזר נתונים שכבר נמחקו; יש להגדיר אותם מחדש. החיבור לשמירה הפרטית שומר את ההגדרות מעתה גם בין התקנות.

אם כבר יש טוקן של `github_feedback` עם הרשאת Contents למאגר הפרטי שנבחר, אפשר להשמיט `storage_token` ולהשתמש בו. עדיין חייבים להגדיר `storage_repository` במפורש. כשל בחיבור מוצג למנהל ואינו יוצר רשימה חלופית בשקט.

אם `storage_token` עדיין מכיל ״הדבק כאן את הטוקן השני״ או `PASTE_YOUR_GITHUB_TOKEN_HERE`, ההגדרה לא הושלמה. החליפו את טקסט הדוגמה בטוקן עצמו ב־Secrets. סיסמת QA אינה טוקן GitHub.

פרטים טכניים למפתח: ללא מאגר פרטי הנתונים נשמרים ב־`~/.local/share/electricity/course_admin.json`; ניתן לבחור נתיב בדיסק קבוע באמצעות `DC_COURSE_CONFIG_PATH`. מאגר ציבורי אינו מתקבל כשמירת הגדרות. חתימת קוד השרת נכללת במפתח המטמון כך שעדכון מנגנון ההרשאות יוצר שירות חדש.

מקורות להגדרה: [הגדרות ו־Secrets ב־Streamlit](https://docs.streamlit.io/deploy/streamlit-community-cloud/manage-your-app/app-settings), [יצירת טוקן GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens).

למיגון ולסלולר נוספה לשונית עצמאית ״דף נוסחאות״, עם נוסחאות החשמל והסוללות המתאימות לכל קורס. בסלולר אין נוסחאות ואט־שעה או מקבילי של שלושה ענפים.

## סימוני סוללה

- `U_t`: מתח ללא עומס.
- `ΔU`: מפל מתח על ההתנגדות הפנימית.
- `U_L`: מתח עומס.
- `R_s = (U_t − U_L) / I`.

הנוסחאות מוצגות ב־MathML, לרבות שברים, חזקות וכתיב תחתי. חישובי טעינה ופריקה מניחים זרם קבוע ומודל אידאלי ללא הפסדים. בתרגילי אבחון נמסר גבול התנגדות לצורך הדוגמה בלבד. אין מיפוי גורף בין ערך התנגדות מוחלט לבין אחוז בריאות הסוללה.

בכל סבב סוללות של עשר שאלות, במיגון ובסלולר ובכל הרמות, שבע שאלות מכילות נתונים ותשובות שלמים ושלוש כוללות תשובות לא שלמות. כל התשובות בשאלות השלמות הן בין 2 ל־10, ללא תשובות 1. נשמרת חלוקת הנושאים: במיגון שבע שאלות מטען ושלוש אנרגיה; בסלולר שבע שאלות מטען ושלוש התנגדות פנימית. בשאלות ההתנגדות הפנימית השלמות משתמשים ב־mV וב־mΩ; חלוקת מתח במיליוולט בזרם באמפר נותנת התנגדות במיליאוהם. בחלק העשרוני יש המרות מדקות לשעות ומשעות עשרוניות לזמן בדקות ולשעות ודקות. סבבי סוללות ישנים מתחדשים בפתיחה הבאה כדי להחיל את החלוקה החדשה; נתוני הביצוע המצטברים נשמרים.

## מאגר ומפתח תשובות

`data/questions.json` הוא המאגר המעודכן מ־22.10.2026: א׳ 50, ב׳ 48, ג׳ 92 ועוד שלוש שאלות השלמה — 193 שאלות בסך הכול, כולל המחיקות ותיקוני המשתמש. הציון משתמש במפתח המשתמש המאושר. בשאלת מיקום לוח החשמל התשובה היא ״כל התשובות נכונות״. שאלות 31–40 מה־PDF הושוו למאגר: שמונה כבר קיימות ושתי שאלות נוספו; שאלה 40 עודכנה לאפשרויות שב־PDF ולמפתח ב׳. שאלה 34 מהצילום נוספה עם תשובה ב׳. המיפוי מתועד ב־`data/question_updates.json`. `data/technical_review.json` שומר את ההערות המקצועיות הקיימות לשאלות שדורשות בירור; התשובות שלהן לא הוחלפו. התרשימים המקוריים המעודכנים נשמרים ב־`data/figures`.

תרגילי המעגל המעורב עודכנו לפי דף הדוגמאות שסופק: נגד בטור לשניים, שלושה או ארבעה נגדים במקביל; שתי קבוצות מקבילות ונגדי טור; נגד במקביל לזוג נגדים בטור; ושני ענפים שבכל אחד זוג נגדי טור. הסכמות שומרות על מיקום המקור ועל סדר הנגדים בדוגמאות. אותיות הצמתים A, B, C וכו׳ ומפת החיבורים מופיעות רק בפתרון מלא. בסכמת השאלה ובהגדלתה אין אותיות צמתים; נקודות החיבור החשמליות נשארות. בפתרון כל מוליך רציף מקבל אותה אות, ומעבר לנגד מגיעים לצומת אחרת. ענפים במקביל חולקים את אותם צמתי קצה. בצמצום נשמרות האותיות של צמתי הקצה וצמתים פנימיים שנבלעו מוסרים. בתחילת הפתרון המלא מוצג עותק של המעגל המקורי עם סימון הצמתים, לפני שלבי הצמצום; סכמת השאלה נשארת ללא סימון גם כשהפתרון פתוח. סגירת הפתרון מסתירה את הסימונים מחדש. אפשר לפתוח כל סכמה להגדלה ולזום. סבבי מעגל מעורב מגרסה קודמת מתחדשים אוטומטית; שאר ההתקדמות נשמרת.

אייקונים וקטוריים נפרדים מלווים את בחירת הקורס ואת כותרתו: מזגן למיזוג, מגן עם מנעול למיגון וטלפון לסלולר. הם משתמשים בצבע הטקסט הקיים כדי להתאים גם למצב לילה.
