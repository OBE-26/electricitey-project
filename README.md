# יסודות החשמל — קורסים ותרגול

```bash
python3 -m pip install -r requirements.txt
streamlit run Electricity-circuit.py
```

לאחר אישור תנאי השימוש הראשון מוצגת בחירת קורס:

- **מיזוג וקירור:** התרגול הקיים; ברמות א׳ וב׳ של חוק אוהם, 9 מתוך 20 תרגילים דורשים מציאת התנגדות ממתח והספק. מבחן עיוני מוגן בסיסמה מגריל 20 שאלות מהמאגר המאוחד של 193 שאלות, מערבב אפשרויות ומציג בסיום דף ציון עם שם הלומד, וממנו כפתור נפרד לסקירת התשובות.
- **מיגון:** התרגול הקיים, שני סוגי מעגלים מעורבים לפי דף הדוגמאות, וסוללות עם 70% שאלות מטען ו־30% שאלות אנרגיה. בכל סבב 10 תרגילי מעגל מעורב: חמישה עם קבוצות מקבילות ונגדים בטור, וחמישה עם ענפי טור המחוברים במקביל. לכל נגד מחושבים הזרם, המתח וההספק, לצד ההתנגדות הכוללת והזרם מהמקור. הפתרון מציג נוסחה וסכמה אחרי כל שלב צמצום.
- **סלולר:** רמות א׳ וב׳ בלבד ושני ענפים בכל תרגיל מקבילי. סוללות עם מטען באמפר־שעה, טעינה, פריקה והתנגדות פנימית. בשאלות ההתנגדות הפנימית מוצגת סכמה של סוללה עם נגד פנימי בטור לעומס המייצג את מעגלי הטלפון; ערכים שטרם חושבו מסומנים בסימן שאלה.

התקדמות התרגול נשמרת בנפרד לכל קורס בדפדפן. מבחנים שהושלמו מוצגים בגרף של אחוז תשובות נכונות לפי מספר מבחן. המבחן הנוכחי והבחירות נשמרים בדפדפן, וכניסה לאחר רענון דורשת סיסמה תקפה. שאלות שלא נענו נחשבות שגויות לאחר אישור הגשה.

ההגרלה מעדיפה שאלות שטרם נצפו ומסיימת סבב של המאגר לפני חזרה לשאלות ישנות. עם המאגר הנוכחי כל מבחן מכיל 20 שאלות שאינן במבחן הקודם. אם המאגר יצומצם, מותרות עד חמש חזרות מהמבחן הקודם; ההגרלה מסרבת לפעול אם אין די שאלות לעמוד בכלל.

## ניהול דרך QA

כפתור QA נמצא בתחתית האתר. סיסמת המנהל הקיימת נשמרה; אפשר להחליפה בהגדרות השרת. במצב QA יש בורר מעבר מהיר בין שלושת הקורסים וכפתור כניסה למבחן העיוני במיזוג וקירור ללא סיסמה נוספת. ההרשאה נבדקת בשרת מול כניסת המנהל; מבחן QA אינו ניתן לחידוש כמבחן רגיל ואינו משנה ציונים, היסטוריה או סבב שאלות אישי. ביציאה מ־QA משוחזר המצב הרגיל. אפשר לערוך את שמות שלושת הקורסים ולהוסיף כמה סיסמאות למבחן העיוני, עם שם, תאריך תפוגה וביטול. תאריך התפוגה כולל את סוף היום לפי `Asia/Jerusalem`. אין סיסמת מבחן פעילה כברירת מחדל: יש להוסיף אותה ב־QA.

הסיסמאות נבדקות בשרת, נשמרות כ־PBKDF2 עם מלח, ואינן נשלחות לדפדפן. התוקף והביטול נבדקים שוב בכל יצירת מבחן, חידושו או בדיקתו. מפתח התשובות אינו נמסר לפני הגשת המבחן. שמות הקורסים משותפים לכל המשתמשים, והסיסמאות מגינות על המבחן העיוני במיזוג וקירור בלבד.

### שמירה משותפת וקבועה

בלי הגדרות נוספות, ניהול הקורסים נשמר בקובץ שרת משותף ב־`~/.local/share/electricity/course_admin.json`. הוא משותף למשתמשים באותו שרת ונשמר בין הפעלות באותו דיסק. באירוח בעל דיסק זמני, לרבות בנייה מחדש, יש להגדיר אחסון קבוע כדי לשמור את השינויים. אפשר לבחור נתיב בדיסק קבוע עם `DC_COURSE_CONFIG_PATH`.

לאירוח Streamlit אפשר לשמור את ההגדרות בקובץ פרטי ב־GitHub. הוסיפו ל־Streamlit Secrets (לעולם לא למאגר הציבורי):

```toml
[course_admin]
password = "YOUR_ADMIN_PASSWORD"
storage_repository = "YOUR_ACCOUNT/YOUR_PRIVATE_REPOSITORY"
storage_token = "YOUR_SERVER_SIDE_TOKEN"
```

המאגר חייב להיות פרטי. הטוקן דורש `Contents: Read and write` למאגר הזה בלבד. הקובץ `course-admin.json` נוצר ומתעדכן בעקבות שמירות ב־QA. אפשר לבחור את מאגר ההערות הפרטי הקיים בתור `storage_repository`. אם לא הוגדר `storage_token`, נעשה שימוש בטוקן של `github_feedback`; עליו לכלול גם הרשאת כתיבה לקבצים. הגדרות המשוב הקיימות אינן משנות את מסלול שמירת הקורסים בלי הגדרה מפורשת. כשנבחר אחסון מרוחק, כשל קריאה או שמירה מוצג למנהל; אין מעבר שקט להגדרות מקומיות שונות.

למיגון ולסלולר נוספה לשונית עצמאית ״דף נוסחאות״, עם נוסחאות החשמל והסוללות המתאימות לכל קורס. בסלולר אין נוסחאות ואט־שעה או מקבילי של שלושה ענפים.

## סימוני סוללה

- `U_t`: מתח ללא עומס.
- `ΔU`: מפל מתח על ההתנגדות הפנימית.
- `U_L`: מתח עומס.
- `R_s = (U_t − U_L) / I`.

הנוסחאות מוצגות ב־MathML, לרבות שברים, חזקות וכתיב תחתי. חישובי טעינה ופריקה מניחים זרם קבוע ומודל אידאלי ללא הפסדים. בתרגילי אבחון נמסר גבול התנגדות לצורך הדוגמה בלבד. אין מיפוי גורף בין ערך התנגדות מוחלט לבין אחוז בריאות הסוללה.

## מאגר ומפתח תשובות

`data/questions.json` הוא המאגר המעודכן מ־22.10.2026: א׳ 50, ב׳ 48, ג׳ 92 ועוד שלוש שאלות השלמה — 193 שאלות בסך הכול, כולל המחיקות ותיקוני המשתמש. הציון משתמש במפתח המשתמש המאושר. בשאלת מיקום לוח החשמל התשובה היא ״כל התשובות נכונות״. שאלות 31–40 מה־PDF הושוו למאגר: שמונה כבר קיימות ושתי שאלות נוספו; שאלה 40 עודכנה לאפשרויות שב־PDF ולמפתח ב׳. שאלה 34 מהצילום נוספה עם תשובה ב׳. המיפוי מתועד ב־`data/question_updates.json`. `data/technical_review.json` שומר את ההערות המקצועיות הקיימות לשאלות שדורשות בירור; התשובות שלהן לא הוחלפו. התרשימים המקוריים המעודכנים נשמרים ב־`data/figures`.

תרגילי המעגל המעורב עודכנו לפי דף הדוגמאות שסופק: נגד בטור לשניים, שלושה או ארבעה נגדים במקביל; שתי קבוצות מקבילות ונגדי טור; נגד במקביל לזוג נגדים בטור; ושני ענפים שבכל אחד זוג נגדי טור. הסכמות שומרות על מיקום המקור ועל סדר הנגדים בדוגמאות. הצמתים מסומנים A, B, C וכו׳: כל מוליך רציף מקבל אותה אות, ומעבר לנגד מגיעים לצומת אחרת. ענפים במקביל חולקים את אותם צמתי קצה. בצמצום נשמרות האותיות של צמתי הקצה וצמתים פנימיים שנבלעו מוסרים. קיימת גם מפת חיבורים נפתחת ואפשר לפתוח כל סכמה להגדלה ולזום. סבבי מעגל מעורב מגרסה קודמת מתחדשים אוטומטית; שאר ההתקדמות נשמרת.

אייקונים וקטוריים נפרדים מלווים את בחירת הקורס ואת כותרתו: מזגן למיזוג, מגן עם מנעול למיגון וטלפון לסלולר. הם משתמשים בצבע הטקסט הקיים כדי להתאים גם למצב לילה.

## בדיקות

```bash
python3 -m unittest discover -s tests
node tests/practice.test.cjs
npm install
node tests/frontend.test.cjs
```

בדיקות הממשק כוללות DOM מול מנגנון השרת האמיתי, מעבר בין קורסים, MathML, צמתים משותפים, צמצומים, הגדלת סכמות, מעבר מסבב ישן ופלטת מצב הלילה. בדיקות המעגלים משתמשות בניתוח צמתים עצמאי כדי לאמת את ההתנגדות השקולה של כל שלב צמצום ואת שימור ההספק. הסכמות והאייקונים נבדקו גם כתמונות נפרדות במצב יום ולילה. בדיקות הניגודיות כוללות טקסט, כפתורים, תשובות נכונות ושגויות ומצב QA. בדיקת תצוגה חזותית בדפדפן לא הושלמה בסביבת העבודה בגלל חסימת כלי התצוגה.
