תיקון תקלה בטעינת רכיב Streamlit

יש להעלות לשורש המאגר OBE-26/electricitey-project את ארבעת קובצי הקוד:
Electricity-circuit.py
courses.js
course_practice.js
course_backend.py

בנוסף, יש להעלות את package.json ואת תיקיית tests המצורפים, כדי שהבדיקות החדשות ירוצו גם במאגר.
לאחר commit בענף main, Streamlit אמור לטעון את הגרסה החדשה. ניתן לבצע Reboot app במסך הניהול אם הפריסה לא מתעדכנת.

תוקן קטע JavaScript שנקטע באמצע מאזין המשוב והתחבר לקטע אתחול אחר. בעקבות זאת לא נשלחה הודעת componentReady ל־Streamlit ונראתה הודעת טעינת רכיב כללית.
שוחזר אתחול הקורסים, ותואמו מחדש קובצי הקורסים והשרת כדי לפתור גם קריאות לפונקציות נוסחאות שלא היו קיימות בגרסה שהועלתה.

החבילה כוללת את הסימולטורים למעגל מעורב ולהתנגדות פנימית, זמינים רק לאחר השלמת כל שלבי התרגיל; ממיר יחידות והסבר מילי/מיקרו/קילו/מגה בכל הקורסים; מצב שבת בירושלים עם שתי נרות וההודעה המבוקשת.

בדיקה מקומית:
npm install --ignore-scripts
npm test

התוצאות: 15 בדיקות Python עברו; בדיקות מחוללי התרגילים בכל הקורסים והרמות, שילוב ממשק ושרת, נוסחאות, ממיר, סימולטור לאחר פתרון ומעברי שבת עברו.
