תיקון סימולטור בקורסים

החליפו בשורש המאגר את Electricity-circuit.py, courses.js ואת course_practice.js בקבצים המצורפים, ואז שמרו/בצעו commit בענף main.

השינוי מוסיף כפתור "סימולטור" בתוך תרגילי המעגל המעורב בקורס מיגון ובתרגילי ההתנגדות הפנימית בקורס סלולרי. הכפתור זמין גם ב-QA, ומופיע רק אחרי השלמת כל שלבי התרגיל; בסוללה משנים התנגדות עומס, ובמעגל המעורב משנים מתח מקור. הסימולטור מציג את הערכים המעודכנים.

נוסף מצב שבת לפי זמני ירושלים: האתר נחסם מכניסת שבת עד צאת שבת, ומוצגים שתי נרות, "שבת שלום", "נשוב לפעול בצאת השבת" ושעת צאת שבת. זמני השבת נטענים מלוח Hebcal ונשמרים במטמון בדפדפן.
