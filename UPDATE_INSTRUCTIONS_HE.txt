הוראות עדכון — חשמל, QA וסוללות

החבילה כוללת את כל קובצי הפרויקט, כולל התיקונים והבדיקות.
התיקון הוכן ונבדק מקומית. הוא עדיין לא הועלה ל־GitHub ולא לאתר החי.

להחלת התיקון במאגר הקיים:
1. חלצו את קובץ ה־ZIP.
2. החליפו בשורש המאגר OBE-26/electricitey-project את שלושת הקבצים:
   course_backend.py
   course_practice.js
   courses.js
   יש להעלות את שלושתם יחד. קובץ Electricity-circuit.py ממשיך לטעון אותם ואינו דורש שינוי.
3. מומלץ להחליף גם את README.md, package.json ותיקיית tests לתיעוד ולהרצת הבדיקות המעודכנות.
4. שמרו את השינויים ב־GitHub. לאחר סנכרון Streamlit, אם האתר לא התעדכן, הפעילו Reboot app.
5. בשדה course_admin.storage_token ב־Streamlit Secrets החליפו את טקסט הדוגמה בטוקן GitHub האמיתי.
   נדרשת הרשאת Contents: Read and write למאגר הפרטי OBE-26/electricity-access.
   אין להעלות את הטוקן למאגר או לצרף אותו לקוד.
6. היכנסו ל־QA. במקרה של תקלה בחיבור השמירה עדיין אפשר לבדוק תרגילים; ניהול סיסמאות ומבחנים עיוניים דורשים חיבור תקין.
   לאחר תיקון החיבור לחצו ״בדיקה מחדש של החיבור לשמירה״.

השינויים:
- בכל סבב מעגל מעורב במיגון נכללות שתי שאלות עם שתי קבוצות מקבילות, נגד ביניהן ונגד בטור בתחתית. ברמה ב׳ אחת מהן משחזרת את התמונה: 45V; נגדים 15, 10, 3, 6, 12 ו־5 אוהם.
- יש להחליף גם את course_practice.js וגם את courses.js לצורך עדכון סוגי המעגלים. סבבי מעגל מעורב ישנים מתחדשים אוטומטית.
- סיסמת מנהל נכונה מאפשרת כניסה ל־QA גם כשחיבור השמירה נכשל, עם הסבר ברור ותיקון החיבור באמצעות רענון.
- בפתרון המלא מוצג תחילה המעגל המקורי מהשאלה עם אותיות הצמתים, לפני שלבי הצמצום. אפשר להגדיל אותו עם הסימונים. סכמת השאלה נשארת ללא אותיות גם כשהפתרון פתוח.
- בכל עשר שאלות סוללות בכל רמה: שבע שלמות, שלוש לא שלמות. תשובות השאלות השלמות הן 2–10, ללא תשובות 1.
- נשמרת חלוקת נושאי הסוללות במיגון ובסלולר. שאלות התנגדות פנימית שלמות משתמשות במיליוולט ובמיליאוהם.
- נוספו המרות דקות לשעות ושעות עשרוניות לשעות ודקות.
- סבבי סוללות ישנים מתחדשים בפתיחה הבאה כדי להחיל את החלוקה. ציונים ונתוני ביצוע מצטברים נשמרים.

בדיקות שעברו:
- 21 בדיקות Python, לרבות הרשאות QA, כשל שמירה והתאוששות בלי החלפת סיסמאות.
- בדיקות מחוללים על 60 זרעים בכל הקורסים והרמות: חלוקה מספרית, יחידות ותשובות המחושבות מנתוני השאלה.
- בדיקות ממשק DOM מול השרת האמיתי, לרבות סימוני צמתים בהגדלה וכניסה ל־QA ללא חיבור שמירה.
- בדיקות תחביר Python ו־JavaScript ובדיקת תקינות diff.

הרצה חוזרת של הבדיקות: npm ci ולאחר מכן npm test.
הבדיקות מקומיות; Secrets והחיבור למאגר הפרטי של האתר החי לא נגישים מכאן.
